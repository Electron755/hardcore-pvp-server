Hardcore PvP

Un seul perso, une seule vie. Duel, échange, village : on joue ensemble.

Télécharger pour Windows Télécharger pour Mac

Un seul fichier, environ 2 Go. Rien à installer.
Mac : dézippe, puis la première fois clic droit sur l'application → « Ouvrir » → « Ouvrir » (l'app n'est pas passée par l'App Store).

  1. Lance HardcorePvP.exe. Windows peut afficher un avertissement : « Informations complémentaires » puis « Exécuter quand même ».
  2. Serveur : le champ se remplit tout seul. S'il est vide, attends 30 secondes et relance.
  3. Crée un compte (nom + mot de passe), puis un personnage.
  4. Rendez-vous au village : tu vois les autres marcher, tu parles avec Entrée.
Hardcore : si ton perso meurt, il est perdu. Le duel d'entraînement est là pour s'y faire sans risque.
Le serveur est en ligne quand l'hôte a lancé la partie.
